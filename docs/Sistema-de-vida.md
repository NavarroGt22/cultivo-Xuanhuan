## SISTEMA DE QUALIDADE (universal)

Reaproveitando a escala já usada pros Talismãs (seção 7 do GDD principal) — assim item, montaria, moradia e até besta de estimação seguem a mesma régua de raridade do resto do jogo, em vez de inventar uma escala nova.

| Qualidade | Multiplicador |
| --- | --- |
| Bronze | x1 |
| Prata | x1.2 |
| Ouro | x1.5 |
| Ouro Negro | x2 |
| Lendário | x3 |

```json
{
  "nome": "Vila à Beira do Lago Espiritual",
  "raridade": "Lendário",
  "valorEmPedrasEspirituais": 15000000,
  "prestigio": 100
}
```

Essa régua única permite gerar combinações praticamente infinitas de moradias, montarias, bestas e parceiros sem cadastrar cada item na mão — um gerador procedural rola raridade + categoria e monta os atributos em cima disso.

### Atributos dos Relacionamentos

```json
{
  "nome": "Lin Yue",
  "tipo": "Namorada",
  "idade": 24,
  "rankCultivo": "Two Force Realm (Martial Master) — Estágio 4",
  "aparencia": 82,
  "inteligencia": 75,
  "riquezaEspiritual": 45,
  "saude": 90,
  "felicidade": 80,
  "compatibilidadeElemental": 88,
  "relacao": 70
}
```

`compatibilidadeElemental` substitui a "compatibilidade" genérica — reflete se as raízes espirituais/afinidades elementais dos dois combinam bem (ver seção 8 do GDD principal), o que no gênero costuma pesar tanto quanto personalidade.

### Luxo

### Atributos da Moradia

```json
{
  "nome": "Vila de Retiro na Montanha",
  "raridade": "Ouro",
  "valorEmPedrasEspirituais": 2500000,
  "manutencao": 15000,
  "prestigio": 95,
  "conforto": 90,
  "seguranca": 85,
  "densidadeEspiritual": 70
}
```

`densidadeEspiritual` é o acréscimo que essa propriedade dá à velocidade de cultivo de quem mora nela — quanto mais perto de uma nascente/veia espiritual, maior o valor.

### Atributos da Montaria

```json
{
  "nome": "Grifo Ancestral",
  "raridade": "Ouro Negro",
  "valorEmPedrasEspirituais": 1800000,
  "manutencao": 20000,
  "prestigio": 95,
  "conforto": 75,
  "velocidade": 98,
  "resistenciaFormacoes": 60
}
```

`resistenciaFormacoes` mede o quanto a montaria aguenta contra ataques baseados em formações/talismãs — relevante porque montarias de elite viram alvo em emboscadas.
